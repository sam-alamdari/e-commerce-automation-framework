# E-Commerce Automation Framework

A Java-based test automation framework for web application testing, built with Selenium WebDriver and TestNG using the Page Object Model (POM) design pattern.

## 📌 Project Overview

This project demonstrates a maintainable and reusable UI test automation framework for an e-commerce web application.

The framework is designed to support automated functional and regression testing while following common test automation practices such as:

- Page Object Model (POM)
- Reusable WebDriver management
- Centralized configuration
- Test setup and teardown
- Maven-based dependency management
- TestNG test execution
- Reusable utility and configuration components

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Java | Programming language |

| TestNG | Test execution and assertions |
| Maven | Build and dependency management |
